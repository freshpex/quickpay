# ADR 0003: Configuration-derived availability and human motion

Accepted. Provider configuration and service enablement jointly determine availability. Missing access produces an unavailable state, never simulated financial success. Financial browser fixtures are confined to test files.

Use real licensed photography and locally optimized video. Motion is part of the product brief: layered scenes, stacking, pinning, a travelling real person, gift-card fan, moving brands and CTA state changes. A global pause and a complete reduced-motion layout are required. Mobile receives still images rather than desktop video. Tailwind handles layout and effects; Motion handles complex transforms. The only global stylesheet contains Tailwind imports, tokens and base focus defaults.
